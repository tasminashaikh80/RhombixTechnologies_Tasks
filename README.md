# Lumen — Digital Art Gallery

A modern digital artwork showcase and exploration platform built for artists and art enthusiasts.

## 📌 About the Project

Lumen provides a platform where digital artists can showcase their artwork and build their portfolios, while art enthusiasts can discover, explore, like, favorite, and follow artists.

This project was developed as part of the Rhombix Technologies App Development Internship.

## ✨ Features

- User registration and login
- Artist and art enthusiast accounts
- Digital artwork upload
- Artwork exploration and search
- Artwork categories
- Artwork detail pages
- Artist profiles and portfolios
- Like and favorite functionality
- Follow artists
- Comments and interactions
- Notifications
- Artist dashboard
- Admin moderation
- Responsive design
- Modern gallery-style interface

## 🛠️ Technologies Used

- React
- TypeScript
- Tailwind CSS
- Supabase
- PostgreSQL
- Lovable
- Vite
